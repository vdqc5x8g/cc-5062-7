# 二维无缝图案绘画工具（Seamless Pattern Painter）

在有限纹理单元上绘画，笔尖越过左/右或上/下边界时按周期关系写入对侧区域，
并实时给出多个重复单元的连续平铺预览。绘制过程本身满足周期覆盖规则，
导出时不做任何边缘模糊或接缝掩盖。

## 怎样启动界面

本工具的绘画窗口是一个浏览器界面，由标准库 `http.server` 提供服务，
内核通过 HTTP API 驱动（无头服务器也能运行与验收）。

```bash
# 可选：安装 numpy 获得加速内核（不装也能跑，会自动用纯 Python 后备路径）
pip install numpy

# 启动绘画窗口（在本目录 seamless_paint/ 下）
python3 -m seamless_paint.webapp --port 8000
```

然后在浏览器打开 <http://127.0.0.1:8000/> 即可绘画。

常用参数：

```bash
python3 -m seamless_paint.webapp --host 127.0.0.1 --port 8000 \
    --width 256 --height 256 --output output
```

- 左侧为纹理单元绘画窗（虚线为周期接缝），可直接沿边缘、角点落笔；
- 右侧为 1×1 到 8×8 的周期连续预览，跨边接缝一目了然；
- 控件包含笔尖半径（允许大于单元尺寸）、柔化、颜色、不透明度、
  斜向越界策略、撤销、清空、新建尺寸，以及保存/下载；
- 内核拒绝的非法输入（如负半径）会以红色状态条回显到绘画窗口，不会崩溃。

## 无头验收与交付物生成

无需浏览器即可复现全部验收场景（斜向细线、半透明大笔尖、角点落笔）：

```bash
python3 -m seamless_paint.demo output
```

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 交付内容

每次“保存”或运行 demo 会在输出目录生成三个文件：

| 文件 | 内容 |
| --- | --- |
| `*_unit.png` | 原始纹理单元（W×H RGBA），可直接用于材质平铺 |
| `*_history.json` | 完整笔画历史（含原始连续轨迹点与全部笔刷参数），可精确重建 |
| `*_preview3x3.png` | 单元的精确 3×3 周期复制，用于检查跨边接缝 |

`*_history.json` 可通过 `seamless_paint.history.load_project` 无损重建出
与 `*_unit.png` 逐像素一致的纹理。

## 周期覆盖规则（内核设计）

- 纹理单元视为平坦环面 R²/(WZ×HZ)。每个笔印在连续平面上定位，
  再把所有与单元相交的周期副本枚举后折叠写入，而不是只复制四条边缘笔印。
- 笔尖半径可大于单元尺寸：枚举范围按“折叠中心到单元两边的覆盖距离”
  计算，跨越多个周期的副本全部计入，不会漏掉额外周期。
- 同一笔印的多个周期副本先求**覆盖并集**
  `cov = 1 - ∏(1 - cov_k)`，再做一次 source-over 合成，
  因此半透明大笔尖不会被当成多层半透明叠加而错误加深。
- 斜向纹样越过两个周期边界时提供两种策略：
  - `neighbor`（默认，邻块延拓）：枚举所有相交周期副本并取覆盖并集；
  - `lattice`（格基内采样）：每个像素只取最近周期副本的值。
    硬笔刷下两种策略数学等价，仅软边在副本重叠区有差异。
- 笔画轨迹按**弧长**等距重采样。指针坐标先折叠到单元，再用最小镜像约定
  解包回连续平面，因此跨边界时通过短的环绕段延续，不会产生穿过整个单元
  的错误直线。
- 四角对称：在角点落笔时，同一笔印在四个角产生完全相同的印记。

## 目录结构

```
seamless_paint/
├── seamless_paint/
│   ├── kernel.py      # 环面绘画内核（numpy 加速 + 纯 Python 后备）
│   ├── pngio.py       # 仅用标准库的 PNG 编解码
│   ├── history.py     # 单元/笔画历史/平铺预览持久化
│   ├── webapp.py      # 标准库 HTTP 服务，内核驱动的绘画窗口
│   ├── demo.py        # 无头验收演示
│   └── static/        # 浏览器绘画界面（HTML/CSS/JS）
└── tests/test_kernel.py
```

## 依赖

- Python 3.9+
- 必需：仅 Python 标准库（`http.server`、`zlib`、`struct`、`json` 等）
- 可选：`numpy`（存在时自动启用向量化加速内核；缺失时自动回退纯 Python）
